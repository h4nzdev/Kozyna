## 🎨 Visual Identity & Design DNA

- **Color Palette**:
  - Warm Ivory: `#F5F0E7`
  - Cream: `#EAE1D4`
  - Espresso: `#261B16`
  - Dark Brown: `#3A2920`
  - Muted Olive: `#777A58`
  - Beige: `#C9BBA8`
  - Gold Accents: `#C59B63` / `#DFC49B`
- **Typography**:
  - `Cormorant Garamond`: Expressive editorial headlines, oversized masthead wordmarks, and italic pullquotes.
  - `Manrope`: Modern, clean body text and supporting monospace tags.
- **Bento Grid Design System**:
  - Applied intentionally to Announcements, Menu Showcase highlights, and Dining Experience.
  - Balanced with traditional editorial layouts in Hero, Story, Chef, and Visit Us to maintain visual rhythm.

---

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite (Pure JavaScript JSX only — no TypeScript)
- **Styling**: Tailwind CSS
- **Smooth Scrolling**: Lenis (`@studio-freight/lenis` / `lenis`)
- **Animations**: GSAP + ScrollTrigger (smooth text reveals, image entrance animations, subtle parallax, and staggered bento card reveals)
- **Icons**: Lucide React
- **Ambient Sound**: Web Audio API ambient acoustic lounge synthesizer (with user toggle)
- **Strictly 2D**: No Three.js, React Three Fiber, WebGL, or 3D environments.
